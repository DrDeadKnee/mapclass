| Boundary | Description |
|----------|-------------|
| config name → gs:// URI | A config string becomes a GCS object path segment |
| GCS blob → torch.load | A (possibly preemption-truncated) remote object is deserialised |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Tampering | `config_prefix` / `validate_config_name` | mitigate | Enforce `^[a-z0-9][a-z0-9\-]*$` on the final config string before any gs:// URI is built; no user-supplied path segments; lowercased to satisfy the regex; regression test TestConfigNaming::test_rejects_traversal |
| T-04-05 | Denial of Service (self) | `gcs_latest_checkpoint` | mitigate | Wrap torch.load in try/except; skip a corrupt/truncated blob and fall back to the next-highest step; (0,None) if all fail — preemption-safe resume; regression test test_corrupt_latest_skipped |
| T-04-06 | Tampering | `torch.load(weights_only=False)` | accept | Only own-produced checkpoints under the project-private bucket are loaded (D-08, IAM via gcloud ADC); documented trust assumption; never deserialise third-party artifacts |
</threat_model>
