# Requirements: MapClass

**Defined:** 2026-05-14
**Core Value:** A trained segmentation model on HuggingFace producing dense per-pixel
land-cover and topography predictions on illustrated regional maps, evaluated by
joint per-pixel NLL = -(log p_land_cover + log p_topography) on held-out synthetic maps.

## Note on Source

No PRDs were present in the ingest set. The requirements below are **derived

## v1 Requirements

### Phase Completion

- [ ] **PHASE-01**: Phase 1 complete — PaliGemma-3B fine-tuned on illustrated map
      terrain symbols with LoRA on SigLIP attention only, Gemma frozen,
      projector trainable; reproducible via `scripts/finetune_paligemma.py`
      (status at bootstrap: **complete**)
- [ ] **PHASE-02**: Phase 2 complete — labelled pixel-pair dataset produced from
      three source families (historical illustrated maps, synthetic illustrated
      maps, satellite-derived imagery) with `image.png`, `land_cover.png`,
      `topography.png`, and `sample_weights.json` per map
- [ ] **PHASE-03**: Phase 3 complete — dense semantic segmentation pipeline
      assembled on the Phase-1 SigLIP encoder with two lightweight heads (9-class
      land cover, 3-class topography) and coarse-to-fine inference; DINOv2 and
      Swin benchmark baselines available
- [ ] **PHASE-04**: Phase 4 complete — segmentation model fine-tuned end-to-end
      on the Phase-2 dataset and published to HuggingFace

### Evaluation

- [ ] **EVAL-01**: Held-out synthetic test set exists, generated by the same
      Azgaar + Pillow pipeline as training but unseen during training
- [ ] **EVAL-02**: Joint per-pixel NLL = -(log p_land_cover + log p_topography)
      computed on the held-out synthetic test set and reported with the
      published model
- [ ] **EVAL-03**: DINOv2 and Swin Transformer backbone variants evaluated on
      the same metric for direct comparison against the primary SigLIP path

### Deliverable

- [ ] **DELIV-01**: Fine-tuned segmentation model uploaded to HuggingFace as a
      public artifact (weights + minimum inference instructions)
- [ ] **DELIV-02**: Published model produces dense pixel-level land-cover (9-class)
      and topography (3-class) predictions on grand-strategy regional map imagery
      at 100–2000 km extent

## v2 Requirements

Deferred to future release. Tracked but not in the current roadmap.

### Real-Domain Evaluation

- **EVAL-R-01**: Hand-annotated real grand-strategy map test set (Label Studio
  or CVAT) to complement the synthetic test set
- **EVAL-R-02**: Joint per-pixel NLL reported on the real-domain test set

### Backbone Exploration

- **BACK-01**: Large first-kernel ConvNet (RepLKNet / SLaK / ConvNeXt direction)
  trained from scratch as a stretch-goal alternative backbone
- **BACK-02**: Progressive backbone unfreezing experiment — unfreeze top-down,
  track segmentation accuracy and run GradCAM / attention rollout at each stage
  to localise the domain gap inside the network

### Synthetic Calibration

- **SYN-01**: Calibrate Azgaar synthetic-height thresholds against SRTM
  statistics (currently deferred)

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| City-plan and large-scale survey map imagery | Extent locked to 100–2000 km regional scale by SPEC |
| Polygonisation / region delineation of contiguous same-class areas | Responsibility of a separate downstream project |
| Production inference service / API | Deliverable is the HuggingFace model, nothing more |
| Google Earth Engine in the critical data path | Direct S3 fetch is the locked source; GEE Dynamic World is optional only |
| Unfreezing the Gemma language model under any scheme | Locked: guarantees zero forgetting of geographic terminology |
| LoRA on any SigLIP layer outside `q_proj` / `k_proj` / `v_proj` / `out_proj` | Locked: only attention projections receive LoRA |
