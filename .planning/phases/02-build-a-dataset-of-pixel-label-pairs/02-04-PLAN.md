| Element84 STAC API → pipeline | Untrusted third-party JSON (STAC items) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Denial of Service | Downloading a full 600 MB Sentinel-2 scene instead of a 4096-px window | mitigate | fetch.py uses rasterio.windows.Window byte-range COG reads only (Task 1); acceptance grep forbids a windowless full read |
| T-02-11 | Denial of Service (self) | Malformed STAC item / missing `visual` asset crashing the batch | mitigate | StacLookupError + per-item try/except returning fetch_failed status; threadpool worker returns the exception instead of raising |
| T-02-12 | Tampering | Region id → data/satellite/<id>/ path traversal | mitigate | Sanitize non-`[\w-]` to `_` before path join (Task 3) |
| T-02-13 | Spoofing | Anonymous S3 / STAC over plain HTTP being MITM'd | accept | All endpoints are HTTPS (earth-search v1, s3 https); data is public open-data with no integrity-critical secrets; rasterio/GDAL upgrade HTTP→HTTPS for these registries |
| T-02-14 | Denial of Service | Malformed/decompression-bomb remote COG | accept | Source buckets are curated AWS open-data registries (not arbitrary upload); windowed reads bound the decoded extent to 4096x4096 |
</threat_model>
