<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Per-map directory contents → tiler | Locally-produced PNGs/JSON (low external trust; integrity matters for EVAL-01) |
| Synthetic train/test boundary → tiler output | The leakage-critical boundary EVAL-01 depends on |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-15 | Tampering | Tiler writing a held-out source's pyramids into train/ (EVAL-01 leakage) | mitigate | Synthetic tiler writes into the SAME train/ or test/ subtree the whole source landed in (Task 2); test_split_subtree_preserved enforces it |
| T-02-16 | Denial of Service (self) | A partially-failed per-map dir (missing one of 4 files) producing a corrupt pyramid tree that breaks the Phase-3 DataLoader | mitigate | Pre-tiling guard skips + logs any map dir missing a required file (Task 2) |
| T-02-17 | Tampering | Pyramid id collisions overwriting tiles across pyramids | mitigate | Deterministic grid-row/col pyramid ids (Task 1) are unique per source map; per-pyramid subdir isolates outputs |
</threat_model>
