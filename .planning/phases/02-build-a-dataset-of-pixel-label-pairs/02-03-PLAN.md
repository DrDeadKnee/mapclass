<objective>
Restructure the synthetic pipeline so each (Azgaar source × render style) is its own
canonical per-map directory (resolved decision A4 — option (a), ~3× volume), add the
locked-shape synthetic loss weights, and implement the seeded stratified-by-template
train/test split with a frozen `split.json` (D-15..D-18) that guarantees EVAL-01's
zero-leakage held-out test set. The synthetic source target is N=100 Azgaar source
maps for v1 (user-confirmed A7 — research recommended N=50; user locked N=100),
which is ~15–16 maps per template across ~12 continent templates.

Purpose: This is the synthetic source family for PHASE-02 and the entire mechanism
for EVAL-01 (the Phase 4 held-out test set). The split must be whole-Azgaar-source-map
so all styles of a held-out source go to test — no cross-style leakage.

Output: refactored `label.py` + `build_dataset.py`, new `synthetic_weights.py`,
deterministic-split + frozen-manifest + no-intersection + locked-topography-threshold
tests.
</objective>
