| T-02-02 | Tampering | Annotation `annotation_id` / `allmaps_id` flowing into downstream filenames | mitigate | Documented for Plan 02: any non-`[\w-]` char replaced with `_` at filename-write time (RESEARCH Security Domain). No filenames written in this plan. |
